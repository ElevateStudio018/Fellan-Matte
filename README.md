# Elevate Studio

Arbetsmaterial för Elevate Studio, separat från Fellan Matte.

- `.claude/agents/elevate-ux.md`: Elevate UX-agenten. Reglerna finns i `docs/elevate/designregler.md` och bygger på designquizet.
- `verktyg/elevate-quiz/`: designquizet med cirka 2 000 frågor. Bygg med `python3 build.py`. Publicerat på https://elevatestudio018.github.io/Fellan-Matte/elevate-quiz/
- `docs/elevate/`: quizsvar och designregler.
- `koncept/`: konceptsajter (sj, blataget, snalltaget). Versionerna med kundernas namn är till för möten och läggs inte ut öppet.
- `docs/leads/`: leadsrapport och mejlutkast.
- `.claude/agents/ux-designer.md` och `verktyg/designquiz/`: den tidigare agenten och quizet (äldre smak).
