# Designquizet

Visuellt quiz med 328 frågor (197 detaljer, 50 sektioner, 41 generellt, 40 hero) som tar fram beställarens designregler för UX-agenten.

- Publicerat: https://claude.ai/artifact/KMGqKrgTKWQfEN725A2YCR (svaren sparas i artefaktens databas, samlingen `quiz`)
- Bygg: `python3 build.py` skapar `quiz.html` (allt inbäddat, för publicering) och `preview.html` (för lokal test).
- Format för frågor: se `FORMAT.md`. Grundstil för alla alternativ: `base.css`.
- Bilder i `img/` kommer från Unsplash, se `koncept/snalltaget/img/KALLOR.md`.
